## 验收证据

本轮结果以 `evidence/stage5-verification.json` 为准；历史证据不自动视为本轮验证。交付包校验和以 `artifacts/distribution/SHA256SUMS.txt` 与 `release-manifest.json` 为准，避免在源码中自引用最终 ZIP 哈希。

验证目标包含插件/技能结构、外部配置启动、依赖诊断、实际 MCP 创建/编辑/渲染/恢复/取消/交付、审片与工作流、草稿结构、解压后可运行以及保留的时序编辑回归。真实模型与剪映实机不在通过范围。

本轮实测：68 项回归通过，0 失败/错误/跳过；插件结构与技能检查通过；重新构建工作台；ZIP 解压后按实际 .mcp.json 启动，41 工具及工具文档一致；外部配置关联、覆盖拒绝、缺媒体工具诊断通过；60 帧本地演示成片；MCP 与 HTTP 共用项目。另行跑通 MCP 重启/去重/取消/交付，以及浏览器创建/编辑/预览/渲染/播放/画布/审片反馈/离线同步/工作流/草稿导出与新目录安装，窄屏无溢出、无页面错误。这里的新目录安装是隔离测试目录中的草稿复制，不是剪映 UI 或 Codex 插件市场安装。

测试中出现的第三方弃用提示为 AnyIO BlockingPortal 和 Pillow getdata；当前测试通过，后续升级依赖时处理。首次回归因测试输出父目录未创建而中断，已修正环境说明并完整重跑；首次技能校验因 Windows 默认 GBK 读取 UTF-8 失败，改为 UTF-8 模式后通过。均未将未完成的首次执行计为通过。
