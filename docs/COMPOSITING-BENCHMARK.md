# 本机合成基准

机器：20 逻辑 CPU，31.8 GiB RAM；不是 8C/32G 云端容量验收。

| room | 1/1 | 55.88/55.88 | 80.98/80.98 | -44.9% | 685.86/685.863 | 154.6 | [1297]/[1297] |

720 = 12 秒 1280×720，1080 = 60 秒 1920×1080；均为 30fps，普通剪辑、中文字幕、半透明 Logo、48k 合成音频（测试配音通道）。room = 原房间工程（包含交叉淡化和原音轨），属于明确回退覆盖。

重复均为新目录、冷图层缓存，顺序运行。旧版本来自切换前不可变备份；编码器、码率公式、输出规格、字体保持不变。新路线含 4 核亲和限制。五次样本只报告中位数和最慢值，不包装为可靠 p95。

临时盘排除原始输入及 output.*（含未完成输出），stderr 在系统临时文件中按 16MB 终止阈值监测（50ms 轮询，可能短暂超量）；RSS 对共享页可能重复计数。采样 CPU 可能遗漏寿命短于 50ms 的子进程，新路线另有 Windows Job 精确子树 CPU 记录。

原房间工程仍走 PNG 兼容路线，4 逻辑核预算下该样本为 55.88s → 80.98s（单次对照）；这是当前明确的性能回退，不属于已优化范围。普通路径的单次编码和原输出参数保持不变。

详细阶段、代码指纹、回退原因、逐次证据见 [performance.json](evidence/compositing/performance.json)。

同 1080p 来源与图层，12 秒峰值 267.9 MB，60 秒峰值 268.5 MB。该局部样本未随总帧数线性增长；不推断任意工程或云端并发容量。
