## 关键适配

完整 D 文档为新项目的制作事实，固定镜头 Plan 保留用于历史项目。旧任务通过 `adopt_legacy_revision(task_id)` 明确选择来源后建立稳定原生工程；原 plan/task/build/delivery 不重写。切换原生后旧制作入口拒绝另起一条执行路径。

每次授权绑定工程修订、文档/输入哈希、实现与供应商配置、复用产物、执行代次、范围、价格和到期时间。`d_authorize_budget`、`d_submit_build` 只产生待确认报价。聊天“确认报价 ID”和报价按钮写入同一授权回执。原范围内执行与交付不追加授权；重新制作必须确认新的范围。

`d_cancel_build`、聊天停止与按钮共用全流程停止。核心已有数据库保存构建代次，短文件锁与原子状态文件保护远端提交边界，不新增数据库。停止后，未提交工作被阻止，已越界请求保留原身份和费用；后台取消本地构建。`d_retry_build` 改为展示恢复报价，不重新发送未知请求。

Agent 继续执行使用控制库的持久 inbox。已知完成事件去重。重启时通过 `clientUserMessageId` 与 `thread/read` 核对原轮次；能确认完成时恢复结果，不能确认时标记需处理，不猜测成功、不盲目重发。旧四工具会话升级时保留原 thread 引用及全部 Web 对话。

素材以 file ID 或获准本地目录访问。图像和上传视频的指定帧、成片的哈希核验帧可返回模型。原 Skill 与完整引用复制到私有 Agent 工作区。外部剪映目录及旧 D 工作区需用户针对具体来源批准；不会迁移个人 Codex 的其他插件或账户。

原生画布展示素材、任务、图层、音轨、转场和整片合成；执行前展示复用与新增范围，确认后映射真实状态。保留 D 的分组、折叠与视口。修改时长采用显式帧槽，不自动推移字幕/音轨；素材不足拒绝报价。保持整片合成。
