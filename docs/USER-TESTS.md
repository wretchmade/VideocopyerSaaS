# 两轮本地用户验收

本记录区分开发者自动化验证与用户在剪映中的实机验收。开发者浏览器/渲染测试不能代替下表中的用户验收。尚未确认本机剪映安装版本及草稿位置。

启动：项目根目录运行 `powershell -ExecutionPolicy Bypass -File scripts/start.ps1`，访问 http://127.0.0.1:8765 。停止：`scripts/stop.ps1`。刷新或 Worker 重启继续核对原请求；返工经新报价确认会创建新尝试。看到“请求待核对”时保留原费用和身份，不能新建同参数付费任务掩盖未知状态。

## 第一轮：从空项目到可编辑工程

建议先使用已有授权素材。任何新的真实模型/媒体付费验收须另行确认测试预算；原 CNY 100 是既有共享配置上限，不代表本轮新增授权。2026-10-20 的自动验收均为本地模拟供应商，费用为零。页面显示预留与待对账事实。

| 步骤 | 操作与预期 | 用户结果 |
|---|---|---|
| R1-01 | 首页写需求并附参考素材；自动进入 `/projects/{id}`，首条消息与文件保留 | 待验 |
| R1-02 | 用对话规划 A/B/C；执行前右侧展示完整 D 节点图；点选 B 指定修改 | 待验 |
| R1-03 | 查看制作范围与预算；授权后出现真实任务状态 | 待验 |
| R1-03a | 运行中说“全部先停，B 换一种表现，其他尽量保留”；立即阻止新提交，显示旧在途请求 | 待验 |
| R1-03b | 修改 B 后先看图和增量报价；已完成 A/C 复用，未完成 C 必须计入执行；确认后才恢复 | 待验 |
| R1-04 | 完成后生成配套交付；浏览器播放，检查人物、镜头、声音、字幕、时长 | 待验 |
| R1-05 | 下载同版 MP4 和 ZIP；校验版本与哈希 | 待验 |
| R1-06 | 关闭剪映；把 ZIP 与 install_draft.py 放同目录，运行安装命令到**新的**草稿子目录 | 待验 |
| R1-07 | 目标剪映打开→改一段字幕或音量→保存→退出→重开；无素材丢失，多轨可编辑 | 待验，需版本/目录 |

安装示例（不会覆盖现有目录）：

```powershell
python install_draft.py --zip jianying.zip --destination "D:\MyJianyingDrafts\VideoCopyer-test-r1"
```

应把 destination 设为目标剪映识别的草稿父目录下一个全新的子目录。本辅助程序仅改包内路径和新目录，不写现有项目、注册表或剪映配置。安装回执是结构/文件证据，不是剪映实机通过。

## 第二轮：重启和局部修改

| 步骤 | 操作与预期 | 用户结果 |
|---|---|---|
| R2-01 | 停止服务并重启；打开 R1 项目，历史对话、方案和交付保留 | 待验 |
| R2-02 | 只改字幕或缩短已完成镜头；查看报价，未改生成输入的素材应复用、无新增付费生成 | 待验 |
| R2-03 | 修改一个镜头画面/人物；新修订独立预算，只重做受影响任务 | 待验 |
| R2-03a | 完成后通过对话重规划 B/C；保留 A，先展示新图和报价，确认后更新对应片段 | 待验 |
| R2-03b | 说“B 提示词不变，再生成一次”；待确认图显示计划重做，新增尝试不命中旧缓存 | 待验 |
| R2-04 | 执行期间刷新，停止，再继续；观察同一请求标识与准确状态 | 待验 |
| R2-05 | 连点提交/导出；同一逻辑操作仅一份结果 | 待验 |
| R2-06 | 新 MP4/ZIP 配套，旧版仍可下载；新目录安装后剪映编辑、保存、重开 | 待验 |
| R2-07 | 新建另一项目，往返切换；附件、会话、方案和任务不串项目 | 待验 |

每次记录：项目 ID、规划修订、制作任务/供应商请求 ID、输入文件 SHA-256、模型固定 ID、预览/ZIP SHA-256、费用/预留与对账状态、剪映版本、安装目录、实际结果、问题截图、修复后复验步骤。

已验证的开发者用例见 `evidence/`；用户测试完成前上述结果维持待验。3D、复杂效果、其他模型覆盖、跨机器二进制分发和公网多用户/收费上线不在本轮通过范围。
